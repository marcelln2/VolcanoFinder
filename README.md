# 🌋 VolcanoFinder

###  Welcome to my Machine Learning project!

---

## Project Overview

This project is focused on understanding the structure of the machine learning pipeline, 
the foundations of Convolutional Neural Networks (CNNs) and how to use such algorithms in simulation using Unreal Engine.

The core idea of the project is that a space probe is launched to look for volcanoes on other extraterrestrial bodies.
If a volcano is found, scientists could begin further investigation into the given planet. 

---

## Setup & Requirements

### Folder & file information

- `/cnns` – a history of previous-best CNNs + the one with the highest accuracy (86.07BCE.pth)
- `/data` – a storage for all the data, both used and raw
- `/notebooks` - all .ipynb / .py files used within the pipeline
- `/train_test_analysis` – the analysis of the models' performance in different aspects
- `/web` – all related files to ensure a working web application (localhost)
- `models.py` - contains the model (CNN)

## Script Breakdown

### `01_img_process.ipynb`
Processes the input images.
- Crops the input images into 128*128 slices and saves them

### `02_train_test_ipynb`
Trains, tests and evaluates the model.
- Loading the data & optimizing it using the torchvision library
- Using the NVIDIA GPU to increase performance & augment the data
- Initializes the optimizer (Adam), the loss function (Binary Cross Entropy) and the scheduler (ReduceLRonPlateau)
- Trains the model
- Validates the model & saves the best one within both the current epoch and the overall training run
- Tests the model against data and saves the best one, while plotting the results

### `03_process_satellite_output.py`
Processes the data generated by the simulation
- Loads the model from the "cnns" folder
- Loads the images and analysis them -> outputs whether an image contains a volcano or not.

### `feautre_maps.py`
Shows the feature maps within the first and second convolutional layers 
- Follows the same pattern as 03 above
- Displays the images using matplotlib

### `AirSim`
This folder should be separate of the VolcanoFinder folder.
- The satellite_nav.py file navigates the satellite and saves the images to the computer
- Flight data and captured images are the folders the above-mentioned python file saves images

## Notes

- Any potential replication of the project inclusive of the AirSim / Unreal Engine simulation should only be done
if the person knows what they are doing. Setting up an outdated UE version with plugins having "interesting"
behavioral characteristics is challenging.
- Within some of the pictures inside the AirSim folder, you might see pictures from Earth. This is because the first
idea was to use the Earth in UE, however, due to plugin issues, Mars was imported instead. (Scaled down 10'000 times)

## Final Thoughts

- After finishing the project and testing the model on pictures of actual volcanoes from Mars, I came to the
conclusion that training the volcano on images from Earth while the potential planets which it analyzes look completely
different is something that will break the whole concept, since it won't be able to identify the same characteristics of
ancient volcanoes. 


- Despite the situation mentioned above, I still consider this project to be a success due to the fact that I've learned
so many skills and valuable knowledge from it, including Machine Learning in general, CNNs, Unreal Engine, MS AirSim, and
of course, domain research.


- If we were to use this model for detecting volcanoes on Earth, a (theoretical) accuracy of 89.09% could be achieved.
